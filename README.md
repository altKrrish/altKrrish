### 🤖 AMSdbGPT — Autonomous Natural Language Database Chatbot
*Built autonomously during AI Internship at VGL Group*

```
User Query (Plain English) ➡️ Intent Parsing ➡️ Neural / LLM Translation ➡️ Optimized SQL ➡️ DB Execution ➡️ Real-Time Insights
```

- **Problem:** Non-technical team members faced high barriers accessing critical data locked in complex SQL database schemas.
- **Solution:** Designed and implemented **AMSdbGPT** entirely from scratch. A conversational AI assistant that interprets user questions in plain natural language, understands semantic intent, autonomously synthesizes valid SQL queries, and queries the database directly.
- **Impact:** Democratized data access across cross-functional teams, reducing query turnaround time by orders of magnitude and eliminating manual technical query writing.
